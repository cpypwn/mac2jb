# VacooTube translations

Strings belong to the JSON files in this folder. Keep keys and placeholders such as {version}, {path} and {language} intact; translate displayed text only. Preserve technical API names and YouTube/SponsorBlock names where they identify external services. Managed controls default to English. Source attribution and contributor/license details are in the repository's root README and notice files.

Validate edited JSON and compare changed screens before packaging. The current fork does not submit translation changes to another project's repository automatically. [Application guide](../README.md).
