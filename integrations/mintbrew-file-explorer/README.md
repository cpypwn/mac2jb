# MintFTP

MintFTP uses the published ftpd-sb 0.1.0 GPU app and MintBrew FTP SDK as its presentation and title-file transfer base. Its dark mint screen, icon, and OunceCake game action are mac2jb adaptations. The original ftpd-sb package and attribution remain in `assets/homebrew-apps/ftpd-sb`.

Press A to start or stop FTP for SmileBASIC's `/save` and `/tmp` files (read/write) and `/rom` (read only). Connect to the console IP shown on screen, port 2121, with anonymous login and passive mode. Press X or tap Browse games to close title FTP and switch to the existing OunceCake game list. Game browsing requires a qualified held filesystem RPC session and is read only. B or Minus returns to MintBrew.
