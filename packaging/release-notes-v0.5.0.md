# mac2jb v0.5.0

<!-- mac2jb-update: {"build":517,"minimumBuild":406} -->

- add demo support with patched bootstrap saving, loading and confirmation.
- introduce the new gui with guided first-time setup, clearer progress and recovery controls.
- integrate HBLauncher, GPUBrewLauncher, IZlauncher with file exchange, BlitBun, VacooTube, OunceCake and Stremio.
- add dedicated tcp streaming for larger stremio frames and improve playback controls.
- add paste and send text to live keyboard with adjustable timing, progress and cancellation.
- update the kurumuz and BermTheSequel forks to their latest upstream revisions and make kurumuz the default host.
- add optional IZMYSH host selection, alongside pepsipu, kurumuz and BermTheSequel, plus attachment to an existing local held RPC session.
- launch a user-selected compatible homebrew folder from held RPC, add compatible custom modules to IZlauncher, open each launcher's app folder, and expose pipeline/acquisition logs under console and developer options.
