# mac2jb v0.6.0

<!-- mac2jb-update: {"build":520,"minimumBuild":406} -->

- add MintBrew, a unified homebrew library that opens automatically after jailbreak and lets users switch compatible gpu apps in one held rpc session.
- bring Stremio, the DOOM proof of concept and OunceCake into MintBrew, alongside the existing small gpu apps. compatible apps can be added or removed while the session is open.
- improve Stremio browsing and playback with controller tab switching, seeking, source resume and clearer on-screen controls.
- improve held rpc workflows with host-only command sending. usb can be disconnected after rpc opens when the Switch keeps its separate ethernet connection and both devices remain on the same network.
